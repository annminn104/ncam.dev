# CD Player: the art side

The suitcase CD player is generated by Python running inside Blender, not modelled by hand.

- `blender/scripts/cdkit.py`: geometry helpers (2D slabs with rounded edges, tubes, lathes,
  stitches, text) and Principled materials, in millimetres.
- `blender/scripts/parts.py`: the CD, the crystal jewel case, the polaroid and the player.
- `blender/scripts/build_player.py`: the web scene, with the names the page drives
  (`src/scene/contract.ts`).
- `blender/scripts/export.py`: the background entry. It meshes curves and text, adds UVs, and
  writes the raw GLB.
- `blender/scripts/hero.py`: the Cycles product still from the design session (docs only).
- `blender/tools/bl.py`: talks to a running Blender through the Blender Lab MCP add-on's socket
  (127.0.0.1:9876, `{"type": "execute", "code": …}` + NUL). Use it for interactive design work;
  the build never needs it.

## Build

Needs Blender 5.2.2 LTS (`/Applications/Blender.app`, or `BLENDER_BIN`).

    pnpm --filter @ncam/cd-player art:build

It writes `public/assets/cd-player.glb` (committed). `src/scene/model-contract.test.ts` checks the
names, the materials and the budget (150k triangles, 4 MB). Rebuild after any change to the scripts.
